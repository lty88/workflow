# 活动资料数据权限配置与验收

## 交付范围

活动范围继续沿用本人、本部门、本部门及下级、参与活动和任务、全公司。新增节点内容、字段原文与编辑、附件查看与下载授权。详情接口在服务端过滤，历史快照、内部意见、审计备注、列表摘要、CSV 导出和文件直链同步执行权限规则。

PC 与 H5 共用同一接口。流程设计器右侧新增“数据权限”页签；配置中心的字段编辑抽屉增加“数据权限与脱敏”；活动详情新增节点资料区；办理抽屉区分“公开结论 / 补充要求”和“节点内部说明”。

## 启用步骤

1. 在项目目录执行 `nvm use`，再执行 `pnpm db:migrate`。增量迁移为 files 表添加 node_id、access_rule、download_rule，并登记版本3。已有账号、密码、活动和附件保持原数据；可重复执行。本次开发没有连接或迁移实际数据库。
2. 在配置中心 → 角色权限，为需要下载的业务角色授予“下载活动附件”。该角色同时需要“查看活动”，下载受该角色自己的数据范围限制。现有角色不会被自动追加新权限。
3. 为总负责人或指定领导授予“查看授权活动内全部敏感内容”，并设置其角色数据范围：全公司，或本部门及下级等。普通进度查看角色的宽范围不会扩大另一角色的敏感授权范围。配置管理员的配置权限单独保留。
4. 如果领导还需要敏感导出或跨节点下载，另授“敏感导出与跨节点下载”。导出仍需要“导出活动”；下载仍需要“下载活动附件”。按节点明确授权的财务受理人可在本节点下载范围内下载，不依赖领导跨节点授权。
5. 在动态表单中编辑敏感字段，展开“数据权限与脱敏”，配置原文查看受众、字段编辑受众及隐藏/部分脱敏。申请必填字段须包含申请人的查看和填写资格；活动名称作为公共流程标识保持共享。保存并发布公司配置。
6. 在流程模板中选中财务或其他节点 → 数据权限。节点内容默认仅本节点当前受理人可见，可以追加指定角色、人员、申请部门负责人或活动执行负责人；也可以明确设置为活动内共享。下载范围单独配置，可排除部分节点受理人。保存并发布流程模板后用于新申请。
7. 已有阶段附件可以点击“权限”设置指定授权，保存后立即按新规则校验。上传者可以收紧；需要扩大已有受众时，由有该资料访问权的配置管理员处理。节点约束和附件附加约束同时满足，附件设置为共享也无法扩大父节点范围。

## 默认行为与版本

- 未配置的申请字段：活动内共享，编辑还需要活动编辑资格。配置后的字段原文、编辑权限由服务器分别判断。
- 未配置的节点内部意见与节点附件：仅当前有效受理人，以及具有该活动敏感查看授权的人员可见。节点状态、办理人、任务状态、公开结论继续共享。
- 现有申请、执行、归档阶段附件：继承活动访问范围；需要保密的已有资料通过“权限”入口设置指定授权。
- 上传节点附件：仅本节点当前有效待办受理人可以操作，办理完成后关闭上传入口。公开阶段意见与执行、归档摘要属于活动内共享内容；敏感判断依据放入节点内部说明或受限附件。
- 节点规则随模板版本冻结到实例；模板新版本用于后续申请。实时组织的停用、角色撤销、部门负责人调整会重新校验节点资料访问。转交只转移当前节点的受理身份。
- 字段读取同时满足历史冻结约束和当前已发布字段约束。当前字段收紧覆盖旧快照；切换新模板或重新提交时保留已有数据约束，避免新版宽权限表单重新暴露旧敏感值。
- 隐藏或只读字段在保存申请时保留服务端原值，篡改被拒绝。脱敏文本不会覆盖原文。费用汇总、列表预算和执行支出也按预算字段约束处理。
- 敏感字段导出额外检查独立授权。系统默认的联系方式排除规则继续保留。

## 附件读取

`GET /api/files/:id` 为下载，检查活动范围、节点内容、附件附加受众、角色下载范围和下载受众。`GET /api/files/:id/preview` 为 PDF/JPG/PNG 在线预览，检查阅读授权；DOCX/XLSX 使用下载入口。两条路径均重新查询实时权限并记录访问。

附件权限修改使用 `PATCH /api/files/:id/access`，包含主单版本和幂等键。文件归属节点不可通过此接口更换。附件授权只影响内容访问，不会赋予审批、编辑或流程调整资格。

成功的敏感详情阅读、文件预览和下载会登记操作人、动作、时间及资源标识，记录中不复制敏感正文。未授权的用户不会收到附件名称、内部意见或字段原文；API 响应使用 private/no-store。

## 手工验收场景

| 场景             | 操作                                     | 预期                                                     |
| ---------------- | ---------------------------------------- | -------------------------------------------------------- |
| 跨部门协作       | 营销打开含财务节点的活动                 | 可见进度和公开结论；看不到财务内部意见、受限字段及附件名 |
| 财务办理         | 当前财务受理人打开自己的待办             | 可读获授权原文、填写内部说明、上传本节点资料             |
| 公开退回要求     | 财务选择退回并填写公开补充要求和内部依据 | 申请人只看到公开补充要求，内部依据按节点受众开放         |
| 领导查看         | 给领导配置敏感查看与正确角色数据范围     | 可读范围内全部敏感资料，范围外活动仍按范围拒绝           |
| 阅读与下载分开   | 领导仅有敏感查看，缺少跨节点下载授权     | 可预览受支持文件，受限附件下载请求被拒绝                 |
| 普通配置管理员   | 只有配置权限的账号访问业务详情           | 配置权限不产生业务敏感阅读资格                           |
| 多角色隔离       | 同一人有全公司普通查看、本部门敏感查看   | 敏感内容只在本部门范围内开放                             |
| 字段防篡改       | 修改隐藏/只读字段的请求内容              | 服务器拒绝越权修改；普通保存不清空原值                   |
| 历史与模板切换   | 查看历史，或切换到新版宽权限模板         | 旧敏感字段约束保留，历史原文不会旁路泄露                 |
| 文件直链         | 使用另一角色复制的受限文件地址           | 阅读无权时404；下载无权时403                             |
| 已有文件收紧     | 上传者将共享文件改为指定授权，再尝试扩大 | 收紧即时生效；上传者扩大范围被拒绝                       |
| 转交、撤销与停用 | 转交节点、移除财务角色或停用人员         | 原受理资格实时失效，新受理人只继承本节点身份             |
| 列表和CSV        | 普通审批人与授权财务分别查看列表、导出   | 列表不泄露隐藏预算，敏感导出需要独立授权                 |
| 权限访问记录     | 授权查看敏感内容、预览、下载             | 留下对应访问记录，不复制敏感正文                         |

## 本次局部校验

类型检查覆盖前端、服务端与领域包；安全局部用例覆盖真实详情读取、文件授权服务、角色范围、快照脱敏、防篡改、列表导出及可重复迁移。未启动项目、数据库或浏览器，未执行端到端验证。
