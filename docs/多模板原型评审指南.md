原型是独立 HTML 页面，可手动打开；读取项目已安装的 G6 本地浏览器包，无需启动 Vue/Node 服务。必须保留整个项目目录结构。浏览器如限制 file 页面本地资源，使用已有可访问的静态站点方式打开；本轮不启动额外服务。

数据存储在当前浏览器 localStorage 中。无法使用存储时，仍可在当前页面评审，刷新后恢复初始数据。原型页面顶部有明确的演示标识，不改变真实数据库。

## 建议评审顺序

1. 模板库查看4套初始模板，按类型和部门筛选。
2. 打开标准教研设计器，点“部门初审”，从左边拖一个“办理任务”到画布下方“参考节点之后”。也可直接点该接入区新增审批，再到右侧改成任务、受理人王舟。
3. 核对新任务在部门之后、教研与营销之前；右侧勾选前置能精确调整依赖。选择新节点，拖入并行任务，检查汇合连线。
4. 编辑节点名称、受理人和预算阈值；故意为审批选苏禾，应用时应提示缺少审批资格。给前置形成环路，应拒绝保存。
5. 拖动画布节点位置，观察依赖连线保持；点“适配”、100%、全屏和Esc退出。
6. 发布前用预算9999.99、10000、12000演算，对比刘文节点；切换申请人为乔安，部门负责人应为杜云。
7. 保存草稿，前往“新建活动”，确认草稿节点尚未进入已发布路线；发布后再预览，出现新节点。
8. 在“新建活动”选择类型与模板，预览后模拟提交。到“实例对比”核对冻结版本。
9. 回到设计器继续修改并发布下一版。再次查看原活动，冻结版本和原路线保持；新活动用新版本。
10. 在已预览但尚未提交时，切到设计器发布新版本，再回申请页直接提交，应提示重新预览。
11. 模板库复制一套模板，修改并发布，再到对应活动类型选择，验证多模板选择。
12. 停用所选模板，申请列表不再可选；已经创建的演示活动仍可查看原快照。

## 评审边界

已实现的原型能力：模板新建/复制/启停、草稿/发布版本隔离、G6展示、节点库拖入参考位置、前后/并行插入、属性与前置编辑、节点删除、预算路线演算、模板选择、提交版本冲突提示、实例快照对比、全屏与缩放。

本轮正式代码已实现：Vue/Naive UI模板库与设计器、MySQL模板域、Node模板版本接口、活动绑定模板、自由连线、拖拽坐标保存、撤销/重做、发布历史和服务端组织授权校验。部署和验收见[实施说明](多流程模板代码实施说明.md)。原型中的受理人枚举只覆盖本次11账号测试场景。
