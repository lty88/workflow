# 流程模板节点删除交互

## 使用方式

1. 在画布或流程目录中选中一个可删除的节点。
2. 点击画布工具栏的“删除节点”，或直接按 `Delete` / `Backspace`。
3. 删除后可点击“撤销”，也可在画布使用 `Ctrl / ⌘ Z` 恢复。

新增节点后自动选中并将键盘焦点放回画布，因此可以直接使用删除快捷键。正常和全屏编辑使用相同入口。属性面板原有的删除入口继续保留。

## 规则

- 删除按钮和快捷键均调用设计器的同一个删除方法，并重新检查节点是否存在、是否为必要审核节点。
- 必要审核节点不可删除；未选择有效节点时不执行删除。
- 保存、发布等忙碌状态及移动只读模式不执行删除。模板设置或路线演算抽屉打开时不处理画布删除快捷键。
- 文本框、多行输入、选择控件、可编辑文本保留原有按键行为；输入法组合输入、修饰键组合、长按重复以及已被其他控件处理的事件不触发节点删除。
- 删除时后继节点继承被删节点的前置关系，清理该节点保存坐标，记录到撤销历史。
- 明确删除会丢弃该节点尚未应用的属性输入；删除仍属于本地模板草案编辑，保存、发布沿用现有操作。

## 校验范围

局部用例覆盖 Delete / Backspace、输入态保护、输入法及长按保护、必要审核保护、无效选择、删除后的依赖重接与原定义保留。既有模板编辑、权限和版本选择用例继续验证兼容。
