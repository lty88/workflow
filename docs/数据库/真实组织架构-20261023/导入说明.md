## 2. SQL 会修改哪些数据

- 物理删除旧 `departments` 数据，写入新 27 个组织及对应负责人。
- 同步 `members`、`roles`、`configuration.published`、`configuration.draft`，并生成配置发布记录。系统读取发布配置，单独插入部门表无法完成替换。
- 保留现有 `admin` 的成员 ID、用户名、密码；赋予配置管理、活动查看、活动删除管理和看板权限。admin 原密码沿用，不自动变成 123456。
- 其他旧账号保留 ID、姓名和密码哈希，统一停用、移至根节点，用户名改为 `old_` 开头，供历史人员引用与原始备份追溯。新员工均为新 ID。
- 保留旧角色以维护历史引用；新增 34 个 `orgsql-` 开头的测试角色。该前缀作为本脚本保留命名空间。
- 原公司基础流程替换为“申请部门负责人审核”，以满足既有配置校验。独立旧模板不改写，另新增“真实组织跨部门测试流程”。
- 草稿组织、角色、流程与发布状态同步；草稿表单保留，草稿菜单及分组采用当前发布版本。原草稿保存在备份中。
- 清理所有登录会话，导入后所有人重新登录。
- 保留活动、流程实例、审批任务、附件及评价。旧实例不自动转交新账号，旧部门字段不自动映射新部门；本次测试应新建活动并选择新模板。旧模板中的旧角色或人员需要重新配置后再使用。

旧账号采用停用方式保留，是为了让历史记录中的人员 ID 继续可追溯；旧部门树会实际重建。账号清单中的 108 人不包含额外保留的 admin。

## 3. 权限与模板受理方式

- 尾号 1/2/3 员工：发起和提交活动、处理自己的任务、执行上报、对应范围的附件与评价。
- 无数字负责人：本部门及下级活动查看、审批、办理任务和部门看板；不授予发起权限，测试发起请使用员工账号，避免申请人自审。
- yuanlingdao：增加全公司普通活动与看板查看。
- xingzhengrenshi：额外承担流程协调、指派执行与归档审核。
- admin：配置管理账号，普通审批使用部门负责人账号。
- 敏感资料仍受原有表单与节点数据权限约束。新增领导和管理员角色均未直接授予全量敏感查看权限。

**“申请人所在部门负责人”始终取申请人的部门，不根据节点名称推断部门。**

例如四川员工发起活动时，所有使用 manager 规则的节点都会指向 sichuan。要交给财务部，应选择“按角色”并选“财务部负责人节点受理”（角色 ID `orgsql-caiwu-review`），该角色仅 caiwu 持有。每个组织都有类似专用受理角色，详见账号清单。

## 4. 导入方法

1. 先保存工作并停止前后端开发进程，备份当前数据库。本脚本要求项目已经初始化且迁移版本 2、3、4、5 已完成。
2. 在数据库客户端连接项目数据库（通常为 `activity_workflow`），使用支持 MySQL 存储过程和 `DELIMITER` 的“执行 SQL 文件/执行脚本”功能，运行完整的 `01-重置真实公司组织与测试账号.sql`。账号需具备本库表读写、建表及创建/执行/删除存储过程权限。
3. 客户端若不能识别 DELIMITER，可在终端使用 mysql 客户端导入，例如：

```sh
mysql -h 127.0.0.1 -P 3306 -u root -p activity_workflow < "/Users/codesun/qh_workspace/work-flow/docs/数据库/真实组织架构-20261023/01-重置真实公司组织与测试账号.sql"
```

其中 root 可换成具有上述权限的数据库账号；密码通过提示输入。数据库登录账号与本文件的 caiwu 等系统登录账号分别管理。SQL 中的部门内容和哈希以 UTF-8 十六进制字面量嵌入，便于避免引号转义和 SQL 模式差异。

4. 运行 `02-只读核对.sql`，应看到 27 个组织、108 个启用测试账号，每个组织四人，负责人无数字。
5. 重新启动项目，重新登录；在组织架构查看负责人和人员分配，在流程模板中查看“真实组织跨部门测试流程”。

脚本首次执行会将原配置、部门、成员、角色存入 `orgsql_rebuild_backups`，备份键为 `real-org-20261023-v1`。备份包含密码哈希，应按数据库备份管理；重复运行不覆盖这份首次备份。

业务写入包在同一个事务中，发生错误会回滚；创建备份表和存储过程属于事务外 DDL。若报“敏感授权仍绑定旧人员”，先将对应表单授权改为准备保留的有效角色再重试，不会自动放宽敏感授权。

重复执行会再次重置这 108 人的密码和测试权限、清除会话，并为测试模板追加一个发布版本。旧模板的默认推荐关系保持原样，新模板需手动选择。
