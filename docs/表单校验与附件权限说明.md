# 表单校验与附件权限说明

## 必填校验

活动创建沿用逐步前端校验。审批、执行汇报、执行完成、归档、取消、调整、转交、删除、组织成员及账号表单增加统一提交前校验：空白文本和空选择视为未填，数字0为有效值。校验未通过时不调用提交接口，字段下方显示错误。

模板保存、发布及设置模块保存也在浏览器先检查必填和数据结构。业务说明、原因、成果摘要不再要求至少5字或10字；节点、部门、成员等名称也按非空处理。自由文本由前端输入控件保留长度上限，服务端保留数据库字段容量、账号密码规则、时间金额格式、权限和流程状态检查。

执行完成时人数为0，需要填写原因，但不要求原因字数。归档时缺少成果附件，则需要填写成果链接；归档审核需要全部检查项确认。

## 两处权限设置

“新上传文件的默认权限”只影响随后新上传的文件。上传时把规则作为该文件的初始设置保存，之后修改默认设置不会批量修改现有文件。

“单文件权限”修改的是该文件当前生效的附加规则。因此不存在两个设置长期叠加、相互覆盖的优先级：上传前使用默认值，上传后使用文件自己的当前规则。

节点内部说明与节点附件分开授权：

- 内部说明是办理人员的详细备注，默认仅节点受理人及具备敏感阅读权限的人员可见，同部门不自动开放。面向申请人的意见放在“公开结论”；需要申请人阅读内部说明时，在模板节点的数据权限中勾选“申请人”，随新版本用于后续申请。
- 文件查看选择“继承所属节点或活动”（`access_rule IS NULL`）时，节点附件沿用节点规则，其他附件沿用活动范围。
- 文件明确选择“活动内共享”时，有权查看本活动的人可查看该附件；“指定授权”只允许所选受众。文件单独授权不会公开节点内部说明，也不会赋予无权访问活动的人活动访问权。
- 动态表单字段附件始终同时满足字段权限；单独分享不绕过字段权限、未提交表单隔离或停用账号限制。
- 下载先满足查看资格及角色“下载活动附件”权限。文件单独设置下载规则时按该规则判断；未设置时继承本文件查看范围，查看也未设置时沿用节点下载规则。

节点上传人在仍有该节点内部阅读资格时，可以分享或收紧自己的附件；其他上传人仍只可收紧，具备活动访问资格的配置管理员可调整授权。权限变更保留审计与主单版本检查。

节点资料页展示服务端实际授权的附件，不再用“能否阅读内部说明”隐藏整个附件区域。未读内部说明时，卡片会区分“可查看已分享附件”和“仅查看公开进度”。

本次修复不需要数据库迁移。现存文件的明确共享规则立即按上述语义生效；未设置规则的文件继续继承节点。

拥有全量敏感资料阅读资格的领导按角色授权查看；敏感导出与下载保持现有独立授权策略。管理员身份本身不自动赋予这些权限。

## 上传区域

普通附件和动态表单附件统一为大尺寸拖拽卡片，显示支持格式、单文件大小、当前数量与上限；上传期间显示进行状态。文件列表加大图标、名称与操作区域，“权限”更名为“单文件权限”。

文件格式、大小、数量和指定授权受众先在前端检查，服务端仍会重复核验内容签名和授权。
