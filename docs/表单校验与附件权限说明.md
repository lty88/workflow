# 表单校验与附件权限说明

## 必填校验

活动创建沿用逐步前端校验。审批、执行汇报、执行完成、归档、取消、调整、转交、删除、组织成员及账号表单增加统一提交前校验：空白文本和空选择视为未填，数字0为有效值。校验未通过时不调用提交接口，字段下方显示错误。

模板保存、发布及设置模块保存也在浏览器先检查必填和数据结构。业务说明、原因、成果摘要不再要求至少5字或10字；节点、部门、成员等名称也按非空处理。自由文本由前端输入控件保留长度上限，服务端保留数据库字段容量、账号密码规则、时间金额格式、权限和流程状态检查。

执行完成时人数为0，需要填写原因，但不要求原因字数。归档时缺少成果附件，则需要填写成果链接；归档审核需要全部检查项确认。

## 两处权限设置

“新上传文件的默认权限”只影响随后新上传的文件。上传时把规则作为该文件的初始设置保存，之后修改默认设置不会批量修改现有文件。

“单文件权限”修改的是该文件当前生效的附加规则。因此不存在两个设置长期叠加、相互覆盖的优先级：上传前使用默认值，上传后使用文件自己的当前规则。

审批仅填写一份活动内共享的审批意见；节点内部说明输入已移除，历史原文保留原记录与授权。

- 附件未明确设置单文件规则时，继承节点查看和下载范围。
- 文件明确选择“活动内共享”时，有权查看本活动的人员可查看；“指定授权”只开放给选定受众。单文件设置独立生效，不修改其他附件。
- 下载同时要求角色具备下载权限和文件下载范围；动态表单附件额外遵守字段权限。
- 本次上传设置只影响随后上传的新文件；已上传文件通过单文件权限调整。
- 节点资料页依据服务端实际授权显示附件，分别标记可查看节点附件、已分享附件或仅查看公开进度。

完整审批操作、退回及评分规则见《审批操作权限与节点评分》。

## 上传区域

普通附件和动态表单附件统一为大尺寸拖拽卡片，显示支持格式、单文件大小、当前数量与上限；上传期间显示进行状态。文件列表加大图标、名称与操作区域，“权限”更名为“单文件权限”。

文件格式、大小、数量和指定授权受众先在前端检查，服务端仍会重复核验内容签名和授权。
