# 前后端实施计划

项目根目录：`/Users/codesun/qh_workspace/work-flow`。后续需求文档统一保存在 `docs/`，历史原型保存在 `prototype/`。

已完成代码实施，当前范围见 [前后端实施说明](前后端实施说明.md)，检查结果见 [前后端校验记录](前后端校验记录.md)。MySQL 按用户选择提供容器配置，稍后启动。

## 实施范围

1. Vue 3、TypeScript、Vite、Naive UI、Pinia，页面按功能拆分，自动文件路由，PC 与移动 H5 共用接口。
2. Fastify、TypeScript、MySQL，真实会话登录、权限与数据范围、动态配置版本、活动完整闭环与文件存储。
3. 动态表单、串行／并行／条件审批、任务版本、加签／新增节点、退回重提、组织成员角色、动态菜单页面。
4. 数据库迁移与种子脚本、MySQL 容器配置、统一接口封装、错误与权限状态。
5. 仅依赖安装、静态检查及必要局部校验；按用户选择不启动 MySQL 容器，不执行构建、项目启动、浏览器预览、端到端验证或 Git 操作。

## 目录

- `apps/web`：Vue 页面与组件。
- `apps/server`：HTTP 接口、服务、MySQL 仓储与迁移。
- `packages/domain`：共享业务类型、校验、权限、流程规则。
- `docs`：需求、接口、部署与交付说明。
- `prototype`：历史离线原型。

本地 MySQL 现有服务不会被操作；默认容器使用 3307 端口，避免与本机 3306 冲突。连接信息从项目 `.env` 读取，不写死个人数据库密码。
