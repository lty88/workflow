# 流程设计器连线修复说明

## 问题与原因

自动排列使用 Dagre 生成节点坐标及连线折点。原设计器随后允许拖动节点或恢复保存坐标，但折线仍使用排列时的绝对折点，导致节点移近后，线还绕向原先位置，出现长尾、折返和重合。

## 修复方式

- 手动布局的模板画布统一启用 G6 最短路径避障路由，清空自动排列遗留折点；节点移动时按当前几何位置计算连接。
- 拖动结束后重新绘制所有连线，覆盖其他节点作为障碍进入或离开路线的情形。
- 恢复已保存的节点位置后重新计算路线；只读状态也可以展示已保存布局。
- 已保存坐标与画布一致时跳过重复平移，避免拖动完成后的重复绘制。
- 连线刷新只调用 `draw`，不会重新排列节点、改变缩放或修改审批依赖。
- 组织架构及审批进度等自动布局展示图继续使用原来的布局折点。

修复集中在 `components/graph/edge-routing.ts` 与 `BusinessGraph.vue`。旧模板保存的是节点坐标，不需要数据库迁移；重新打开时应用新的连线规则。“自动排列”仍用于整体整理节点间距。

## 局部校验

使用项目已安装的 G6 5.1.1 几何算法，不创建画布或启动项目：

1. 布局产生的旧折点被设计器配置覆盖，业务颜色保持不变。
2. 纵向终点从 600 移到 160 后，连线折点回到当前两节点之间。
3. 横向以及反向移动按当前位置计算连线。
4. 中间节点挡路时绕行，移开后恢复紧凑路线。
5. 松手后刷新所有连线，保留连接方向、审批关系、颜色和虚线样式，原输入对象不被修改。
6. 既有组织、模板及审批图模型用例继续通过。

## 手动验收步骤

1. 打开流程模板，添加一个后续节点，将它拖到较远位置，再拖回前置节点下方。
2. 确认连线随间距缩短，没有延伸到旧位置的长尾。
3. 将节点横向或反向移动，检查连接箭头仍对应原先的审批依赖。
4. 将另一个节点移入路线中，再移开，检查避障路径随之更新。
5. 保存草稿后重新进入，确认节点位置保留，路线按当前位置重新计算。
6. 使用撤销、重做和自动排列，检查节点布局与连线保持一致。

本次仅执行静态检查与必要局部校验；未启动应用、构建或浏览器验收。
