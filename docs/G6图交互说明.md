# G6 图交互说明

日期：2026-10-21。按用户补充要求，组织架构、流程设计和审批图统一采用 **AntV G6 5.1.1**。外围表单、列表、确认和抽屉继续使用 Naive UI。

## 已接入位置

| 页面 | 图形数据与交互 |
| --- | --- |
| 配置中心 → 组织架构 | 部门、负责人和人数；可切换显示成员。点击部门筛选成员并同步组织树，点击成员打开编辑抽屉；上级部门停用时下级和成员显示失效状态 |
| 配置中心 → 动态流程 | 从当前草案生成节点依赖图，展示串行、并行、汇合、条件、知会和后续指派／执行／归档阶段。点击审批或任务节点进入规则编辑；可保存并前插、后插、并行新增 |
| 配置中心 → 路线演算 | 选择申请人和预算，展示本次命中的节点、跳过节点及解析出的受理人 |
| 发起申请 → 路线预览 | 使用服务端解析结果绘制实际路线，提交前检查分支和受理人 |
| 活动详情 → 审批流程与办理 | 使用服务端节点实例绘图，展示等待、办理中、完成、失效、跳过和受理异常；点击节点筛选对应个人任务与意见，再办理或转交 |

实际审批图默认仅展示当前申请轮次，历史开关可展示此前申请节点。退回、拒绝、撤回、取消审核和已取消显示单独状态分支。后续业务阶段由实际主单状态着色。

## 共用交互

- 拖动画布平移、滚轮缩放，移动端可用放大和缩小按钮。
- “适应画布”重新显示完整路线。
- 可搜索并定位节点，支持键盘选择；图形之外保留可读的表单和个人意见列表。
- 点击节点显示选中边框，业务状态颜色保持；节点和边来自配置及服务端数据。
- 组织或流程存在环路／缺失前置时显示问题并保留外围编辑入口。

流程模板中通过编辑“前置节点”维护依赖；图中的插入操作更新同一份草案。实际审批办理仍提交个人任务标识、版本和幂等键，服务端重新检查权限、归属和状态。图上选择节点不直接改变审批结果。

## 实现结构

| 文件 | 职责 |
| --- | --- |
| `apps/web/src/components/graph/BusinessGraph.vue` | G6 懒加载、尺寸监听、画布生命周期、选择、定位、缩放与错误提示 |
| `apps/web/src/components/graph/models.ts` | 组织、审批模板、运行实例转换为纯图数据 |
| `apps/web/src/components/graph/types.ts` | 图组件和选择事件类型 |
| `apps/web/src/components/config/OrganizationPanel.vue` | 组织图与部门／成员管理联动 |
| `apps/web/src/components/config/WorkflowPanel.vue` | 模板图与节点规则、插入和演算联动 |
| `apps/web/src/components/activity/WorkflowTimeline.vue` | 实际审批图、历史轮次、个人任务与意见联动 |

采用 [G6 官方 Dagre 分层布局](https://g6.antv.antgroup.com/manual/layout/dagre-layout)，组织和审批数据共用一个图组件。组件按容器尺寸初始化，卸载时销毁图实例并断开尺寸监听；更新请求串行合并，避免快速切换配置时重复创建画布。

本轮已通过 Vue 类型检查、33 个组件的静态语法检查和包含 G6 图模型的17项局部校验。按用户开发规则，实际画布交互的浏览器验证留待明确启动预览时执行。
