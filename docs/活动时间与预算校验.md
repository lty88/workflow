# 活动时间与预算校验

## 时间

活动申请允许选择当前时刻，也允许补录已开始或已结束的活动。提交时不再比较开始时间与服务器当前时刻，避免填写表单、上传附件或保存草稿期间流逝的时间导致提交失败。

前后端仍检查必填、有效日期，以及结束时间严格晚于开始时间；保留用户原本选择的时间，不自动改成提交时间。执行阶段到计划开始时间后才能开始的规则保持不变。

## 预算

取消金额一亿元的业务上限，保留非负、最多两位小数及整数分安全精度检查。金额按十进制拆分为整数分，合计后通过字符串格式化回元，避免大金额和小数加法丢失分位。

前后端复用相同预算合计函数：专家费、会务费与差旅费自动汇总；服务端从明细重新计算，忽略传入的不一致总额。预算在页面以只读金额展示，零预算有效，不再受输入控件旧上限影响。

填写中空明细暂按0展示，必填错误提示在费用明细自身。明细格式错误也不重复提示预算必填；只有合计超出系统安全精度时，预算提示准确的范围错误。

例如专家费50元、会务费100000000元、差旅费60元，预算总额为100000110.00元，可以正常校验并提交。

本次修改无需调整表结构或导入数据。局部校验覆盖填写耗时、历史补录、时间先后、大额预算、小数精度、零预算、缺失明细及真实提交服务路径。
